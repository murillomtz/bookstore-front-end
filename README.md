# Frontend da Livraria

Aplicação Angular para administrar a interface de uma livraria. A estrutura inclui páginas e serviços para consultar, criar, editar e remover livros e categorias.

## Tecnologias principais

- TypeScript
- Angular 11
- Angular Material
- HTML e CSS

## Backend relacionado

Este frontend foi feito para trabalhar com a API [Bookstore Back End](https://github.com/murillomtz/bookstore-back-end). Configure o endereço da API no ambiente Angular antes de iniciar.

## Executar

Com Node.js instalado:

```bash
npm install
npm start
```

Acesse `http://localhost:4200`. Para gerar a versão de produção, use `npm run build`.
